# 📸 Telegram Bot Assistant for Vitaliy Bystrov Photography

AI-ассистент для фотографа Виталия Быстрова (Тбилиси, Грузия). 
Бот автоматически отвечает на частые вопросы клиентов, показывает прайс и собирает заявки на съемку.

## 🌟 Возможности
- Мгновенный ответ на команду `/start`
- Информирование о пакетах (BASIC, BUSINESS, PREMIUM)
- Подсказки по локациям в Тбилиси
- Сбор контактов для бронирования дат

## 🚀 Как запустить
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` и добавьте туда ваш `BOT_TOKEN` от @BotFather.
3. Запустите бота: `python bot.py`
